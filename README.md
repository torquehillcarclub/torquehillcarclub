# TORQUE HILL - Cameron Highlands Car Club

A fancy, animated landing page for the TORQUE HILL car club featuring automotive-themed animations and modern design.

## 🎨 Features

### Realistic Automotive Animations
- **🔧 Turbocharger**: Professional SVG turbo with spinning turbine blades and glowing effects
  - Realistic turbine blade design with gradient fills
  - Smooth continuous rotation
  - Pulsing glow and shadow effects
- **🏔️ Mountain Scenery**: Floating mountain silhouettes creating depth
- **🛣️ Hill Road**: Animated winding road with moving lane markings
- **⚙️ Mechanical Gears**: Two counter-rotating gears with realistic teeth
  - Synchronized rotation
  - Metallic gradient styling
- **🔥 Exhaust Flames**: Flickering flame animations
  - Realistic fire gradient (red to yellow)
  - Natural flickering motion
- **✨ Smooth Transitions**: Hover effects, fade-ins, and parallax scrolling

### Sections
1. **Hero Section** - Eye-catching landing with animated logo and automotive elements
2. **About Section** - Club information with animated statistics
3. **Events Section** - Upcoming events calendar
4. **Gallery Section** - Photo showcase (ready for your images)
5. **Contact Section** - Membership application form

### Design Elements
- Automotive red/black color scheme
- Responsive design for all devices
- Custom fonts (Orbitron & Rajdhani)
- Glow effects and shadows
- Mobile-optimized (animations disabled on small screens for performance)

## 🚀 Getting Started

Simply open `index.html` in your web browser to view the landing page.

## 📱 Responsive Design

The page adapts to different screen sizes:
- Desktop: Full animations and effects
- Tablet: Optimized layout
- Mobile: Simplified animations for better performance

## 🎯 Customization

### Adding Photos to Gallery
Replace the gallery placeholders in `index.html` with your actual images.

### Updating Contact Information
Edit the contact details in the Contact Section of `index.html`.

### Modifying Colors
Change the color scheme in `styles.css` by updating the CSS variables at the top of the file.

## 📄 Files

- `index.html` - Main HTML structure
- `styles.css` - All styling and animations
- `script.js` - Interactive features and animations
